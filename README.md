# Free Card Table

A real-time browser card table for four players. It is intentionally loose, so you can use it for many different card games.

## Features

- Four seats around one large table
- Shared room link
- Face-down deck starts on the right side
- Left click flips a card
- Right click and drag moves a card
- Cards in a player's hand can be flipped privately
- Reset button collects everything and starts over
- Distribute button splits the deck into the four hands

## Run Locally

```powershell
npm.cmd install
npm.cmd start
```

Open:

```text
http://localhost:3000
```

## Deploy

Push this folder to GitHub, then deploy it as a Node web service on Render or a similar host.

Build command:

```text
npm install
```

Start command:

```text
npm start
```
